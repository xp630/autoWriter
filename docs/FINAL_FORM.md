# FINAL FORM · 这个系统最终是什么

> 定稿 2026-09-14（owner 定终局，助手补一层）
> 一句话：**你负责定义"我要什么、什么不能碰"，AI 负责决定"现在该做什么"。**
> 每次想加功能之前，先读这一页。

---

## 一、终局不是"更强的 AutoWriter"

是一个 **Account Operating System（账号操作系统）**：

- 可以托管**目标**、托管**账号**、长期**自主经营**的 AI Operator
- 用户看到的界面不是"AI 写作工具"，而是 **AI 运营控制台**
- **文章可以再生，账号认知不可再生**——所以系统最值钱的产物不是文章，也不是 prompt，
  而是"这个号过去做过什么、结果如何、为什么、现在相信什么、正在验证什么"

写文章只是它的一项 Skill。自动发布只是它的"手"。

## 二、六层（你定的五层 + 我要补的第六层）

```
① Goal          我要什么（目标 / 预算 / 边界）
② World Model   外部世界发生了什么（信号 / 热点 / 同类 / 平台变化）
③ Account Model 我的账号现在怎么样（内容 / 数据 / 目标进度）
④ Agent         下一步做什么（判断 → 决策 → 计划）
⑤ Execution     真正去做（写、排版、发、回评、取数）
⑥ Identity      这个号是谁 ←【补的一层，见下】
```

贯穿六层的地基：**Memory · Evidence · Experiment · Policy**

### 为什么必须加 ⑥ Identity

Operator 最容易造成的破坏**不是做错事，而是"以不像你的方式正确地做事"**。
一个没有 Identity 层的 ④Agent，会稳定地产出"正确，但没有你"的内容——
那正是 EP04 已经论证过的失败模式。

所以 Identity 不是风格参数，是**可判定的硬约束**：

```text
voice          这个人怎么说话（自白式 / 不宣布成功 / 不喊口号）
non-negotiable  哪些东西永远由人出：观点、角度、经历、是否发布
forbidden      永远不做：伪精确数字、拔高句式、发明经历、为了活跃而行动
```

它是 ④ 的裁判，也是 ⑤ 的最后一道闸。**没有 ⑥ 的五层系统，会把账号经营成别人。**

## 三、控制台长什么样（Phase 3 的真实界面）

```
账号：AI 技术公众号

目标            2 粉 → 1000 粉 ／ ¥0 → ¥1000/月
AI 状态         正常运行
正在做          研究 3 个内容机会 ／ 监测 2 个热点 ／ 复盘昨日文章
最近决策        为什么选这个选题 ／ 为什么放弃另外两个
需要你确认      发现一个可能改变账号方向的机会      [查看]
最近学习        "实践型内容的关注转化高于纯热点"
```

**理想使用姿态：你不需要每天"使用它"，你偶尔管理它。**
正常 → 自主处理；异常 → 自主判断；重大问题 → 找人。

## 四、终局的真正瓶颈不是 AI 智力

是三件外部条件，按难到易排：

| 瓶颈 | 性质 | 现在能不能解 |
|---|---|---|
| **Outcome 数据回流** | ③ 的燃料。阅读/分享/涨粉/评论要进得来 | **能，而且最该先做**——不依赖 AI 能力，只依赖"你肯把数据粘回来" |
| **平台执行权** | ⑤ 的手。发布/取数 API | 个人主体订阅号受限，短期靠人工，不解 |
| **样本量** | ③④ 的意义。n<20 时任何"学习"都是幻觉 | 只能等真实时间，不可压缩 |

**推论**：想让终局不变成漂亮的幻觉，下一步该投的是 **③ Account Model 的回流管道**，
不是 ④Agent 的脑子。脑子再聪明，账本空转就是自我催眠。
这也是当前系统里最薄、最便宜、却最少被想做的一块。

## 五、路线与进入条件（不给日期，给条件）

```
Content Observer  →  Decision Assistant  →  Autonomous Operator
   （现在）             （有数据形状后）         （四个条件齐全）
```

| 阶段 | 在验证什么 | 进入下一阶段的条件 |
|---|---|---|
| **Observer** | AI 能不能理解"什么值得我注意" | Opportunity Adoption Rate 高（人真的用这些入口） |
| **Decision Assistant** | 判断痕迹能不能长成认知 | ≥20 篇真实 Outcome + 数据开始有形状 + 归因可复核 |
| **Operator** | 交还执行权之后还能不能变好 | 真实反馈 + 长期状态 + 明确权限 + 稳定平台能力 + **可靠的人类边界** |

**Observer 是终局的第一块砖**，不是 Operator 的缩水版。
`Signal → Opportunity → Human Decision` 现在做的每一件事，都是在为 ④ 攒"什么叫值得"的判断标准。

## 六、反目标（不做的东西，写死）

```text
❌ 排行榜 / 评分 / 推荐系统          （n<20 时是噪声）
❌ 自动发布 / 自动修改已发布内容      （平台受限 + 不是当前验证变量）
❌ 多 Agent / Sub-Agent 平台         （没有第二个真实需求之前不建）
❌ 自研 Agent Runtime               （pi 可换，宿主只做 UI + 数据 + 交互）
❌ 伪精确概率与评分                  （样本不支持，出现即拒收）
❌ 为了"24/7 在跑"而制造任务          （WAIT / ABORT / ASK_HUMAN 是合法动作）
```

---

## 七、停止线

这个系统的价值上限由**内容成立**决定，不由**系统成立**决定。

如果 90 天后它仍然只服务一个几百粉的号，那"最终形态"就该收敛成
**一份流程 + 一个薄薄的工具 + 一套账号认知**，而不是一个产品。

**判据**：连续两周没有服务过一次真实发布的工程项 → 冻结。
