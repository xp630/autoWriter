# 策略库 · 功能清单与操作说明

> 面向使用者的一页说明。实现细节见 `CONTENT_STRATEGY_V2.md`。
> 一句话定位：**策略是资产，文章是执行结果。** 策略库就是把"我每次是怎么决定这篇怎么写的"沉淀下来，并让它被复用、被真实战绩校正。

---

## 1. 入口

侧栏 → **创作** → **策略库**

> 策略库没有 ⌘ 快捷键（⌘0–⌘6 留给仪表盘/写文章/我的文章等高频页）。

来源有两条：
- 在**写文章页**点「采用策略并开始创作」→ 该策略自动进入策略库，状态变`已采纳`
- 在**写文章页**只生成不落库的情况不会入表；库里只存"已经形成决策"的策略

---

## 2. 功能清单

| 功能 | 怎么操作 | 说明 |
|---|---|---|
| 浏览 | 进入即是卡片列表，按创建时间倒序 | 最多显示 100 条 |
| 按模式筛选 | 顶部 `全部模式 / 借势拆解 / 命题策划` | 后端过滤，不是前端截断 |
| 按状态筛选 | 右上状态下拉：`全部状态 / 候选 / 已采纳 / 已归档` | 可与模式叠加 |
| 搜索 | 搜索框输入关键词 | 后端模糊匹配四处：**标题、主题（题目）、创作角度、核心主张** |
| 看单条详情 | 卡片上点 **详情与战绩** | 在列表下方展开详情面板 |
| 看被哪些文章使用 | 详情面板底部「采用记录」 | 每条显示 `文章 #id` 或 `未生成文章（已采纳）` |
| 看使用次数 / 最近使用时间 | 卡片底部 + 详情汇总条 | `采用 N 次`、`最近 3 天前` |
| 回填效果数据 | 采用记录行内的输入框 + **记录** 按钮 | 阅读 / 点赞 / 收藏 / 评论 / 涨粉 / 主观分 / 备注 |
| 复用策略 | 卡片或详情点 **从这条重新创作** | 跳转写文章页并预填，见 §5 |
| 归档 | 卡片右侧 📦 图标 | 不再出现在默认列表，可切`已归档`找回 |
| 删除 | 卡片右侧 🗑️ 图标 | 有确认框；**采纳与战绩记录一并删除** |
| 手动刷新 | 右上角 **刷新** | 切换筛选/翻页时会自动重拉 |

## 3. 卡片上每个元素是什么意思

```
◎ 命题策划   个体账本视角                        ★ 8.2
不结婚的十年，我算了一笔账
年轻人不是拒绝婚姻，而是不愿进入低质量关系
[情绪·共鸣] [目标·评论] [事实风险·中] [证据 1/3] [候选]
◎ 采用 2 次                        最近 3 天前
[详情与战绩] [从这条重新创作] [📦] [🗑️]
```

| 元素 | 含义 |
|---|---|
| `◎ 命题策划` / `◇ 借势拆解` | 策略模式。命题策划=只有一个题目推演出来的；借势拆解=从一篇参考文迁移出来的 |
| `个体账本视角` | **创作角度**（切入框架），不是标签，是这篇的立场装置 |
| `★ 8.2` | **推荐指数**：这个角度在当前赛道值不值得写（0–10） |
| 第二行大字 | **标题方向**（不是成品标题，是策略给的方向） |
| 第三行 | **核心主张**——全文要证明的那句判断 |
| `情绪·共鸣` | 希望读者产生的主导情绪，会影响标题、开头、结尾写法 |
| `目标·评论` | 这篇要拿到的结果，会影响结构（评论→留站队问句；涨粉→给关注理由） |
| `事实风险·中` | **这个角度有多容易让 AI 编造事实**。高=需要大量数据/案例/人名。会向正文下发更强的禁令 |
| `证据 1/3` | **成立度**：3 项素材里已备好 1 项。见 §4 |
| `候选 / 已采纳 / 已归档` | 生命周期状态 |
| `采用 2 次` | 该策略被采纳过几次（一条策略可服务多篇文章，1:N） |

## 4. 证据账与成立度（最该理解的一个概念）

**前面的字段决定"想写什么"，这一项决定"这篇到底能不能成立"。**

详情面板里的「证据账」长这样：

```
证据账 · 决定这篇能不能成立          [ 1/3 · 33% ]
◯ 待核实：某城市十年居住成本区间
● 一组读者的真实案例            ← 已勾
◯ 一个可公开检索的判例文号
还差 2 项。未勾上的素材，正文里会强制留「待补充」占位，AI 不会替你编。
```

- 点圆圈即可在 `未备 → 已备好` 之间切换，**立刻写库**，列表徽标同步
- 已勾上的会划线（表示"这条解决了"）
- 三种颜色：<span>红 `0/n`</span> 一条都没备 ｜ 橙 部分备齐 ｜ 绿 全备齐

### 它会真实改变 AI 的行为

勾与不勾不是记账，是**开关**：

| 状态 | 下发给正文生成/润色的约束 |
|---|---|
| `已备好` | "用户已提供的证据，**可以直接写进正文**" |
| `未备` | "正文里必须留**「待补充」占位，绝对不得臆造**" |

而且 `事实风险` 会随成立度自动推导：全备齐→低；列了但一条没备→**高**（此时正文被要求"定量表述一律占位"）；部分备齐→中。

> 所以正确用法：**先勾证据，再生成正文**。你勾得越多，AI 越能写实；一条不勾，它就只能在观点层面写作——这是设计，不是 bug。

## 5. 「从这条重新创作」会发生什么

点它之后：

1. 跳转写文章页，**模式自动切成该策略所属模式**
2. 主题框被填成 `标题方向 / 核心主张`
3. 大纲框被填成该策略的叙事骨架（`## 1. 钩子… ## 2. …`）
4. 直接进入 **Step 2 编辑大纲**
5. 在 `strategy_articles` 里**新增一条采纳记录**——所以同一策略复用两次，`采用次数` 会变成 2

这是 1:N 的实际意义：**一条策略可以喂给公众号长文、小红书笔记、知乎回答、头条文章**，各自是独立的执行记录、独立的战绩。

> 交接是一次性的：进过一次写文章页就不会重复触发，不会每次进去都被塞同一个策略。

## 6. 效果回填（为 P2 策略评分准备）

在详情面板「采用记录」区，每条记录一行输入框：

`阅读` `点赞` `收藏` `评论` `涨粉` `主观分` `备注` + **记录**

- **只填你手上有的**，空白项不会被写入（不会把已有数字清成 0）
- 可以随时改，覆盖式更新
- 存好后详情汇总条立刻重算：`平均阅读 / 平均评论 / 平均收藏 / 平均涨粉 / 平均主观分`
- 备注建议写"为什么"，例如 `评论区站队很明显`——将来回看比数字有用

> 现阶段**全是手动录入**，不自动抓取。故意如此：100 条真实数据胜过 10000 条推测数据。攒够十几条，才有资格谈"哪类角度在我这个赛道更有效"。

## 7. 三种状态怎么用

| 状态 | 含义 | 建议用法 |
|---|---|---|
| `候选` | 生成出来了，还没采纳 | 攒着的想法；换渠道时可能就用上了 |
| `已采纳` | 至少被采纳过一次 | 有战绩可查的策略，重点看它的平均值 |
| `已归档` | 不想再看到，但不舍得删 | ⚠️ 目前**默认列表仍会显示它**，要看未归档的请手动选「候选」或「已采纳」 |

归档 ≠ 删除：归档保留全部采纳与战绩；删除会连带清掉它们。

---

## 8. 可见范围（身份隔离）

- 策略库**只显示当前身份 + 升级前的历史记录**（历史数据 `profile_id` 为空，对所有人可见，不会隐身）
- 你和你老婆各自身份下看到的策略互不相同
- 想给"另一个身份"复用某条策略？目前没有跨身份复制功能（未做）

## 9. 常见问题

**Q：卡片里没有「证据 x/y」徽标？**
说明这条策略没有证据账——多是 V3 之前生成的旧数据。旧数据不猜，一律视为无证据；重新生成一次策略就有了。

**Q：点「从这条重新创作」后，大纲是策略给的骨架，我改了还算用这条策略吗？**
算。采纳记录已经生成，文章入库后会关联到这条策略（战绩也归它）。改大纲只是执行层调整。

**Q：`未生成文章（已采纳）`是什么？**
你采纳了它、但还没生成正文（或生成失败）。这条执行记录 `article_id` 为空，等正文入库时回填。

**Q：策略库和「选题中心」什么关系？**
目前选题中心仍是骨架页（未实现）。按 V3 的定位，**选题会降级为"策略的一个来源"**（`source_type='manual'`），并入策略库，不再做并列的两个页面。

**Q：为什么没有评分/推荐排序？**
需要真实战绩才做得准。目前只能按 `★ 推荐指数`（AI 给的）排序，那是预测不是实测——这正是回填的意义。

## 10. 已知行为问题（不是使用问题，是实现缺口）

- **归档不隐藏**：默认状态筛选是「全部状态」，所以`已归档`的策略照样出现在列表里。这让“归档”几乎等于没作用。合理默认应是只显`候选 + 已采纳`（具体改动：默认 status 从 `all` 改成一个“未归档”虚拟值，后端加一条 `status != 'archived'`）。一行代码加一个测试，要做告诉我。
- **无分页/排序控件**：目定 100 条上限、只按创建时间倒序。策略多了之后需要“按成立度/按平均评论/按推荐指数”排序——那要等战绩数据够多才不致于排个并猜。
- **采用记录不显示文章标题**：只有 `文章 #id`，得自己去「我的文章」对。应该在后端一次 join 把标题带回。

## 11. 明确不做的事

- 不把「标题方向」当成品标题——它是策略产物之一，最终标题在正文阶段定
- 不自动抓取平台数据（等官方接口或稳定爬虫，先手动）
- 不做跨身份复制/共享策略
- 不在库里直接编辑策略正文（策略由 AI 生成 + 用户勾选证据，不提供手写表单；将来若要"手写策略"会以 `source_type='manual'` 引入）
