## 三、三模块架构

```
┌─ Capture   记录观察和问题           ← 输入
│
├─ Think     Idea Interview = 观点提炼 ← 处理
│
└─ Write     文章创作                 ← 输出（带闸门：观点未确认不进 Write）
```

| 模块 | 职责 | 对应 | 状态 |
|---|---|---|---|
| **Capture** | 记录"看到了什么"+"什么让我停下" | Stage 1+2 | 已部分存在 |
| **Think** | Idea Interview / 审问器（3 问） | Stage 3 | **Season 1 最优先** |
| **Write** | 从观点到文章 | Stage 4 | Season 2 才做 |

---

## 四、核心对象：Episode

**Episode 是贯穿三层的核心对象。** 所有数据都挂在 Episode 下：

```
Episodes 表（中心）
├─ Capture   观察 + 疑问
├─ Think     一句话观点
├─ Write     公众号正文
├─ Feedback  阅读 / 点赞 / 留言
└─ Reflection 沉淀 + 是否仍认同
```

旧模型是 Article-centric（新功能围绕"文章"展开）。新模型是 Episode-centric。

## 五、Episode 6 阶段生命周期

| Stage | 类型 | 今天的例子 |
|---|---|---|
| 1 | 观察 | 陌生人点赞 |
| 2 | 疑问 | 他真的看了吗 |
| 3 | 观点 | 早期创作者需要确认有人在看 |
| 4 | 文章 | 公众号正文 |
| 5 | 反馈 | 阅读量 / 点赞 / 留言 |
| 6 | 沉淀 | 一个月后是否仍认同 + 是否连回主线 |

**没有 Stage 6，文章只是文章。有了 Stage 6，文章是成长的证据。**

## 六、3 问审问器（Idea Interview v1）

**核心**：观点藏在观察后面。所以**先观察，再思考，最后才写**。

```
[01] 今天你观察到了什么？
[02] 今天有什么事让你停顿了 3 秒？
[03] 你最想说的一句话是什么？
```

| 问 | 作用 |
|---|---|
| Q1 观察 | 把眼睛打开 |
| Q2 停顿 | 把注意留住 |
| Q3 一句话 | 让观点自己走出来 |

**填不出就不写。** 这就是审问器的灵魂——不是工具帮你做，是你自己卡住就别写。

## 九、4 阶段路线图（Phase）

```
Phase 1: 解决自己的问题
Phase 2: 观察自己解决问题的过程
Phase 3: 验证别人是否也这样
Phase 4: 先不做任何产品，我还没想清楚
```

**执行顺序**：
```
Phase 1 写文章
  → Phase 2 边写边记
    → Phase 4 等"想清楚"
      → Phase 3 才允许做产品
```

**Phase 4 是闸门**：是"我有没有资格开始想 Phase 3"的自检。

**当前确切位置**：
- Phase 1 跑了大半（4 版本 + 第一篇 + 周记素材）
- Phase 2 还没开始（**需要从下一篇起开始记观察日志**）
- Phase 4 没到（仍在"想"的阶段）
- Phase 3 远着

## 十、产品原则

1. **系统不能替用户形成观点。** 系统只能帮助用户发现观点。
2. **系统负责放大，不负责创造。**
   ```
   用户有观点 → 系统放大
   而不是：用户没观点 → 系统硬编
   ```
3. **生成是后置能力。思考是前置能力。**
   ```
   先想清楚 → 再生成
   而不是：先生成 → 再修改
   ```

## 十一、暂缓开发清单

以下功能**全部暂停**（n=2 阶段数据全是噪声）：

- 策略排行榜（样本不足）
- 策略推荐（无统计意义）
- 爆款预测（数据不足）
- 自动选题（容易制造垃圾内容）
- 战绩评分（噪声大于信号）

**数据阶段规划**：
- 0~100 篇：只记录，不评分，不推荐
- n ≥ 20 + 最近 90 天：才允许进入推荐系统

---

## 十二、明确的减法

这一周确定要减的事：

- 别再加产品功能（默认折叠现有闸门，不强制）
- 别追求 30 篇（改成 12–15 篇 + 12 篇周记 = 每 3 天 1 篇）
- 别依赖 AI 起草（周记和主题文章第一稿必须自己写）
- 别管阅读量/点赞（看板只看转发）
- 别问"对不对"（写完就发，3 天后回来看一眼）
- 别每篇都做配图（只有数据图值得配）
- 别维护完整文档（USER_GUIDE / CHANGELOG / WEEKLY_RECAP 之外不再加新文档）

---

## 十三、90 天目标

**不是**涨粉 1000。

**而是**：连续写 30 篇，每篇满足：

- ✓ 有明确观点
- ✓ 有认知位移
- ✓ 有证据支撑
- ✓ 值得保存
